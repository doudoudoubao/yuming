# 安装

三种方式，选一种就行。装完默认是**只监控不下单**，不会花你一分钱。

要求：**Python 3.10 或更高**（开发和测试环境是 3.11 / 3.13）。
一台能长期开着的机器（VPS、树莓派、家里的小主机都行）——
抢注要在域名释放那一刻在线，笔记本合盖就没戏了。

---

## 方式一：一键脚本（推荐）

```bash
git clone -b claude/domain-monitor-auto-register-5z21z6 \
  https://github.com/doudoudoubao/yuming.git
cd yuming
./install.sh
```

脚本会问你三件事（都可以回车跳过，之后再补）：

1. 要监控哪些域名
2. Telegram Bot Token
3. 你的 Telegram user id

然后自动完成：找合适的 Python → 建虚拟环境 → 装依赖（失败会自动换清华镜像重试）
→ 生成 `config.yaml` → 把密钥写进 `.env`（权限 600）→ 跑一遍自检。

脚本是**幂等**的：已存在的 `config.yaml` 和 `.env` 不会被覆盖，重复运行安全。

装完就能用：

```bash
.venv/bin/python -m domain_monitor list              # 看监控列表
.venv/bin/python -m domain_monitor check example.com # 查一个域名
.venv/bin/python -m domain_monitor run               # 跑起来
```

`.env` 会被**自动读取**，不需要手动 `source`。

### 开机自启

```bash
sudo ./install.sh --systemd
journalctl -u domain-monitor -f     # 看日志
```

## 方式二：让 AI 帮你装

**不需要把脚本发给它。** 脚本就在仓库里，AI clone 下来自然就有了。
你只要给它仓库地址和分支名。

> ⚠️ **分支名必须给。** 代码在 `claude/domain-monitor-auto-register-5z21z6` 分支上，
> `main` 分支只有一个 README。不指定分支的话 AI 会 clone 到一个空仓库，
> 轻则装不上，重则它照着 README 自己动手把代码重写一遍。

把下面整段复制给你服务器上的 AI 助手（Claude Code、Cursor、Codex CLI 等）：

````text
帮我在这台机器上安装一个域名监控与自动抢注程序。你只负责安装，不要写代码。

仓库：https://github.com/doudoudoubao/yuming.git
分支：claude/domain-monitor-auto-register-5z21z6   ← 必须用这个分支

步骤：

1. clone 指定分支到 /opt/domain-monitor：
     git clone -b claude/domain-monitor-auto-register-5z21z6        https://github.com/doudoudoubao/yuming.git /opt/domain-monitor

2. 立刻检查 clone 结果：ls 应该能看到 install.sh、domain_monitor/、
   config.example.yaml。如果只看到一个 README.md，说明分支拿错了——
   停下来告诉我，不要自己新建任何文件，也不要照着 README 去实现功能。

3. 确认有 Python 3.10 或更高版本。没有就装一个并列版本，
   不要动系统自带的 python3 软链。

4. 运行安装脚本。注意你的 shell 多半没有 TTY，脚本会自动切成非交互模式，
   要预填配置就用环境变量：
     cd /opt/domain-monitor
     DM_DOMAINS="域名1.com 域名2.io" ./install.sh
   （把 DM_DOMAINS 换成我要监控的域名；不确定就先留空，之后再加）

5. 跑自检并把完整输出贴给我：
     .venv/bin/python -m domain_monitor test

6. 验证真的能查到域名状态，把输出贴给我：
     .venv/bin/python -m domain_monitor check example.com
   正常应该显示「已注册」和到期日期。

7. 配置开机自启：sudo ./install.sh --systemd
   然后确认 systemctl status domain-monitor 是 active (running)。

硬要求：
- 不要开启自动下单。config.yaml 里 purchase.enabled 必须保持 false。
  我要先只用监控功能跑一段时间。
- 不要向我索要任何注册商的 API Key，那部分我自己填。
- Telegram 的 token 我会单独给你，只能写进项目根目录的 .env（权限 600），
  绝对不要写进 config.yaml，不要提交到 git，不要打印在日志或聊天里。
- 任何一步失败，把原始报错原样贴给我，不要自己改配置绕过去，
  也不要跳过失败的步骤继续往下走。
````

### 怎么确认 AI 真的装好了

别只信它说「安装完成」。让它把这三条的**实际输出**贴给你：

| 命令 | 正常的样子 |
|---|---|
| `ls /opt/domain-monitor` | 能看到 `install.sh`、`domain_monitor/`、`config.example.yaml` |
| `.venv/bin/python -m domain_monitor -V` | `domain-monitor 1.0.0` |
| `.venv/bin/python -m domain_monitor check example.com` | `🔒 example.com 已注册 \| 注册商=... \| 到期=...` |

第三条最关键——它证明依赖装好了、网络通了、RDAP 查询真的能跑。
如果显示「查询失败」，就是那台机器访问不了 RDAP 服务器，得先解决网络。

再确认一下这两件事：

```bash
grep -A2 "^purchase:" /opt/domain-monitor/config.yaml   # enabled 应该是 false
ls -l /opt/domain-monitor/.env                          # 权限应该是 -rw-------
```

> 让 AI 装可以，但**注册商的 API Key 建议你自己手填**。
> 那是能直接花钱的凭据，少一个环节经手就少一分风险。

## 方式三：手动安装

```bash
git clone -b claude/domain-monitor-auto-register-5z21z6 \
  https://github.com/doudoudoubao/yuming.git
cd yuming

python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

# 生成配置
python -m domain_monitor init config.yaml
# 编辑 config.yaml，填上要监控的域名

# 密钥单独放，不要写进 config.yaml
cat > .env <<'EOF'
TG_BOT_TOKEN=你的token
TG_CHAT_ID=你的userid
EOF
chmod 600 .env

python -m domain_monitor test     # 自检
python -m domain_monitor run      # 跑起来
```

## 装完之后

1. **先只监控。** 默认 `purchase.enabled: false`，只推送不下单。跑几天，
   看看状态判断和 Telegram 通知是不是符合预期。
2. 想开自动抢注，读 [README 的「抢注要准备什么」](../README.md#抢注要准备什么)——
   开户、充值、开 API、IP 白名单，一步都不能少。
3. 开之前先 `dry_run: true` 演练，确认整条链路通了再改 `false`。

## 装不上的常见原因

**`没找到 Python 3.10+`**
```bash
sudo apt update && sudo apt install -y python3.11 python3.11-venv   # Debian/Ubuntu
sudo dnf install -y python3.11                                      # CentOS/RHEL
brew install python@3.11                                            # macOS
```

**`创建虚拟环境失败`**
Debian/Ubuntu 上通常是缺 venv 模块：`sudo apt install -y python3-venv`

**`依赖安装失败`**
脚本会自动换清华镜像重试。还不行就是网络问题，手动指定镜像：
```bash
.venv/bin/pip install -i https://pypi.tuna.tsinghua.edu.cn/simple -r requirements.txt
```

**自检里 `RDAP 查询 ✗`**
机器访问不了 RDAP 服务器。检查防火墙 / 代理；国内机器有时需要给
`rdap.verisign.com`、`rdap.org` 放行。DNS 探测那一项能过就说明基础网络没问题。

**`DNS 探测 ✗ 不可用`**
`pip install dnspython`。没有它冲刺阶段会退化成直接问注册商，慢一些但仍可用。

**Telegram 收不到消息**
必须**先主动给你的机器人发一句 `/start`**，否则机器人无权给你发私聊。
另外确认 `TG_CHAT_ID` 填的是你自己的数字 id（找 @userinfobot 拿）。
