# 安装

三种方式，选一种就行。装完默认是**只监控不下单**，不会花你一分钱。

要求：**Python 3.10 或更高**（开发和测试环境是 3.11 / 3.13）。
一台能长期开着的机器（VPS、树莓派、家里的小主机都行）——
抢注要在域名释放那一刻在线，笔记本合盖就没戏了。

---

## 方式一：一键脚本（推荐）

```bash
git clone https://github.com/doudoudoubao/yuming.git
cd yuming
./install.sh
```

脚本会问你三件事（都可以回车跳过，之后再补）：

1. 要监控哪些域名
2. Telegram Bot Token
3. 你的 Telegram user id

然后自动完成：找合适的 Python → 建虚拟环境 → 装依赖（失败会自动换清华镜像重试）
→ 生成 `config.yaml` → 把密钥写进 `.env`（权限 600）→ 跑一遍自检。

脚本是**幂等**的：已存在的 `config.yaml` 和 `.env` 不会被覆盖，重复运行安全。

装完就能用：

```bash
.venv/bin/python -m domain_monitor list              # 看监控列表
.venv/bin/python -m domain_monitor check example.com # 查一个域名
.venv/bin/python -m domain_monitor run               # 跑起来
```

`.env` 会被**自动读取**，不需要手动 `source`。

### 开机自启

```bash
sudo ./install.sh --systemd
journalctl -u domain-monitor -f     # 看日志
```

## 方式二：让 AI 帮你装

把下面整段复制给你服务器上的 AI 助手（Claude Code、Cursor、Copilot CLI 等）：

````text
帮我在这台机器上安装并配置一个域名监控与自动抢注程序。

仓库：https://github.com/doudoudoubao/yuming
分支：claude/domain-monitor-auto-register-5z21z6

请按这些步骤做，每一步做完告诉我结果：

1. 确认这台机器有 Python 3.10 或更高版本。没有就先装（不要动系统自带的
   python3 软链，装一个并列版本即可）。
2. 把仓库 clone 到 /opt/domain-monitor（或者你觉得合适的位置），
   然后运行 ./install.sh
   —— 注意：你的 shell 大概率没有 TTY，脚本会自动切成非交互模式。
   要预填配置就用环境变量，例如：
     DM_DOMAINS="我要监控的域名1.com 域名2.io" ./install.sh
3. 装完后运行 .venv/bin/python -m domain_monitor test，把自检结果贴给我。
   RDAP 那一项失败通常是网络问题，告诉我具体报错。
4. 用 .venv/bin/python -m domain_monitor check <某个域名> 验证真的能查到状态。
5. 问我要 Telegram Bot Token 和 user id，写进项目根目录的 .env 文件
   （TG_BOT_TOKEN= 和 TG_CHAT_ID=），并把 config.yaml 里 telegram.enabled 改成 true。
   然后再跑一次 test，确认我能收到测试消息。
6. 配置 systemd 开机自启：sudo ./install.sh --systemd，
   然后确认 systemctl status domain-monitor 是 running。

几条硬要求：
- 不要开启自动下单。config.yaml 里 purchase.enabled 保持 false。
  我要先只用监控功能跑一段时间。
- 密钥只能写进 .env（权限 600），绝对不要写进 config.yaml，
  也不要提交到 git，更不要打印在日志或聊天里。
- 如果哪一步失败了，把原始报错贴给我，不要自己瞎改配置绕过去。
````

> ⚠️ 让 AI 装可以，但**注册商的 API Key 建议你自己手填**。
> 那是能直接花钱的凭据，少一个环节经手就少一分风险。

## 方式三：手动安装

```bash
git clone https://github.com/doudoudoubao/yuming.git
cd yuming

python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

# 生成配置
python -m domain_monitor init config.yaml
# 编辑 config.yaml，填上要监控的域名

# 密钥单独放，不要写进 config.yaml
cat > .env <<'EOF'
TG_BOT_TOKEN=你的token
TG_CHAT_ID=你的userid
EOF
chmod 600 .env

python -m domain_monitor test     # 自检
python -m domain_monitor run      # 跑起来
```

## 装完之后

1. **先只监控。** 默认 `purchase.enabled: false`，只推送不下单。跑几天，
   看看状态判断和 Telegram 通知是不是符合预期。
2. 想开自动抢注，读 [README 的「抢注要准备什么」](../README.md#抢注要准备什么)——
   开户、充值、开 API、IP 白名单，一步都不能少。
3. 开之前先 `dry_run: true` 演练，确认整条链路通了再改 `false`。

## 装不上的常见原因

**`没找到 Python 3.10+`**
```bash
sudo apt update && sudo apt install -y python3.11 python3.11-venv   # Debian/Ubuntu
sudo dnf install -y python3.11                                      # CentOS/RHEL
brew install python@3.11                                            # macOS
```

**`创建虚拟环境失败`**
Debian/Ubuntu 上通常是缺 venv 模块：`sudo apt install -y python3-venv`

**`依赖安装失败`**
脚本会自动换清华镜像重试。还不行就是网络问题，手动指定镜像：
```bash
.venv/bin/pip install -i https://pypi.tuna.tsinghua.edu.cn/simple -r requirements.txt
```

**自检里 `RDAP 查询 ✗`**
机器访问不了 RDAP 服务器。检查防火墙 / 代理；国内机器有时需要给
`rdap.verisign.com`、`rdap.org` 放行。DNS 探测那一项能过就说明基础网络没问题。

**`DNS 探测 ✗ 不可用`**
`pip install dnspython`。没有它冲刺阶段会退化成直接问注册商，慢一些但仍可用。

**Telegram 收不到消息**
必须**先主动给你的机器人发一句 `/start`**，否则机器人无权给你发私聊。
另外确认 `TG_CHAT_ID` 填的是你自己的数字 id（找 @userinfobot 拿）。
